# 产品概述

## 定位

多平台社媒视频下载器（桌面应用）。**只下载视频，不下载图片**——这是不可让步的约束。

## 覆盖平台

抖音、TikTok、小红书、Instagram、Pinterest、X.com、Bilibili、YouTube（依赖 yt-dlp extractors，完整实测见 `docs/design-docs/platform-harness-research.md`）。

## 核心用户旅程

1. 粘贴链接（支持多行批量、自动去重、自动抽取 URL）→ 自动探测
2. 探测结果分三类呈现：可下载（可选画质）/ **纯图文帖自动跳过**（明确提示）/ 失败（按三分法给原因）
3. 选择下载目录 → 全部下载（受并发上限约束）或单条下载
4. 进度逐条可见：下载百分比 → 合并音视频 → 完成（可打开文件位置）

## 界面与主题（TD-FE-017/018/020，2026-10-07 参考图定版）

- **左侧栏**：品牌 TikDown + 版本号；统计卡「7天/总下载次数（[重置] 清零）」——计数口径为**下载成功次数**，localStorage 持久化；统计卡「磁盘剩余空间」（下载目录所在卷，`disk_free` 命令，失败显示 —）；大按钮「粘贴/下载」；底行「⚙ 设置 + 主题切换」。
- **主区**：顶部宣传语条（平台清单来自 PLATFORMS，兼窗口拖拽区）→ 任务卡列表（缩略图在左）→ 底部状态栏：左 = 组件 tag（就绪实线框/未就绪虚线框）+ 消息，右 = 队列汇总（待下载/下载中/完成/失败）。
- **黑白双主题**：白色（默认）/ 黑色两套，侧栏圆形按钮切换，重启保持；**首次启动跟随系统**（prefers-color-scheme）。视觉为纯黑白灰硬边框风格，无彩色强调。

## 失败提示策略（三分法）

| 类别 | 触发特征 | 用户提示方向 |
|---|---|---|
| 提取器问题 | yt-dlp 不认识链接 / 解析失败 | 引导升级 yt-dlp（组件面板"更新"） |
| 登录墙 | 需要 cookie / 私密内容 / 年龄限制 | 引导到设置开启 Cookie 读取（见 cookie-access.md） |
| 网络 | 连接失败 / 403 / 超时 | 提示需要代理或稍后重试 |

## 组件管理（用户可见语义）

- 首次使用引导安装 yt-dlp（必需）与 ffmpeg（合并音视频需要）；显示体积与来源，用户主动点击。
- 安装位置 `~/.tikdown`；组件可随时删除重建。
- 设置里可手动指定本机已有的 yt-dlp/ffmpeg 路径（优先级最高，但仍过版本门槛）。
- 自动探测优先引用**系统 PATH** 中版本合格的组件（免重复下载），其次 `~/.tikdown` 副本；版本过旧的 PATH 组件会被跳过。
- yt-dlp 从 GitHub 下载失败时（国内网络），提示引导到"设置 → 手动指定路径"。

## 设置项清单

| 设置 | 范围 | 默认 |
|---|---|---|
| 下载目录 | 持久化 | 上次选择 |
| yt-dlp / ffmpeg 手动路径 | 文件选择器 | 空（自动探测） |
| 并发下载上限 | 1–4 | **1** |
| Cookie 模式 | 不使用 / 浏览器登录态 / cookies.txt 文件 | 不使用 |
| 语言 | 跟随系统 / 中文 / English | **跟随系统**（TD-FE-019，2026-10-07） |
