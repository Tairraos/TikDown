## 决策

| # | 决策 | 依据 |
|---|---|---|
| D1 | 主题 = 纯黑白灰单色，两套 CSS 变量（`data-theme="light"/"dark"`），侧栏按钮切换，localStorage 持久化，**首次启动跟随系统**（prefers-color-scheme） | 用户"黑白两种 theme"+参考图只有月亮按钮；跟随系统是首次体验的合理默认 |
| D2 | i18n 自研极简字典（zh/en 两份 key-value），**不做框架引入**；设置项 `Settings.language: "system"/"zh"/"en"`（默认 system），仅前端使用（后端 Settings serde 忽略未知字段，不加死字段） | "无聊技术"原则；语言是纯 UI 关注点 |
| D3 | 下载统计 = localStorage `{ total, days: Record<"YYYY-MM-DD", n> }`，任务 **done 事件**计数；7 天 = 本地日期回溯 7 天求和；重置清零 | 参考图"7天/总下载次数 [重置]"；无需后端 |
| D4 | 磁盘剩余空间 = 新 Rust 命令 `disk_free(path)`（fs4 crate，查询下载目录所在卷），完成事件/启动/换目录时刷新；失败显示"—" | 参考图"215.3G 磁盘剩余空间"；fs4 比 shell df 解析无聊且跨平台 |
| D5 | 组件 tag（TD-FE-014）迁入状态栏左侧，未就绪时内联展开下载/指定入口 | 参考图无独立组件面板；"状态栏"即其归宿 |
| D6 | 版本展示用现有 `__APP_VERSION__`；宣传语平台清单由 `PLATFORMS` 动态拼装（zh/en 双标签） | 单一事实来源 |

## 任务分解

1. **Rust**：`src-tauri/src/disk.rs`（fs4 free_space）+ `disk_free` 命令注册 + 单测（真实目录 >0；不存在路径 Err）。
2. **lib 层**：`src/lib/i18n.ts`（字典/resolve/t/参数插值）、`src/lib/theme.ts`（load/save/apply）；`icons.ts` + moon/sun；`types.ts` Settings.language + PLATFORMS.labelEn；mock IPC 增 `disk_free`。
3. **state 层**：`src/state/stats.ts`（计数仓）；`tasks.ts` 增 `onDone` 钩子（done 转变沿触发）。
4. **ui 层**：`app.ts` 重排（grid 侧栏 + 主区）；`taskList.ts` 文案走 i18n；`corePanel.ts` 迁入状态栏 + i18n；`settingsPanel.ts` 增「语言」块 + i18n；`styles.css` 重写（双主题变量 + 侧栏布局 + 黑白风）。
5. **测试**：i18n（解析/回退/字典 key 齐全）、stats（计数/7 天窗/重置/持久化）、theme（持久化/系统回退）、settings 默认 language、tasks onDone。
